BokyDo

Self-hosted, Todoist-style task manager.

Self-hosted Early development AGPL-3.0

BokyDo is a free, open-source, self-hostable task manager. It does the job Todoist does, on infrastructure you control: natural-language quick add, projects, boards, filters, collaboration, bring-your-own-key AI, a REST API and an MCP server so your assistant can read and write your tasks. It is in early development.

Early development. Expect breaking changes and data migrations. Back up your instance database before upgrading, and read the release notes.

Features

  • Self-host with Docker Compose. One stack on your own hardware or your own VM. No Boky-operated backend, ever.
  • Natural-language quick add. Type a task the way you would say it — dates, priorities, project and context are parsed out of the sentence.
  • Projects, boards and filters. Organise by list, by board, or by a saved filter that updates itself.
  • Collaboration. Share a workspace with other people on your instance.
  • Bring-your-own-key AI. Optional AI assistance using your own provider key. No shared key, no proxy, no metering.
  • REST API. Everything the UI can do, over HTTP.
  • MCP server. Expose your tasks to an MCP-capable assistant over the same API surface.
  • Voice capture. Dictate a task instead of typing it.
  • Security-first. Design driven by a documented threat model; see SECURITY.md in the repository.

Your data

BokyDo is self-hosted. You run the server, and your task data lives on the instance you operate. There is no Boky-operated cloud backend, and no Boky analytics. If you enable the optional AI features, requests go from your server to the provider you configured, using your key.
