BokyQR

Android QR scanner. Bring your own key.

Offline-first Android Apache-2.0

BokyQR is an offline-first QR and barcode scanner for Android. Camera frames are decoded on the device — nothing is stored, uploaded or logged by default. If you want to know whether a scanned URL is dangerous, you can hand that URL to a reputation service yourself, using an API key you supply. Each check tells you exactly what it is about to send before it sends it.

Features

  • On-device decoding. The barcode model runs locally: the Play flavour bundles ML Kit inside the APK, the F-Droid flavour uses ZXing. Either way it is pure on-device computation.
  • Gallery import, without a media permission. Import a QR from a photo through the Android system photo picker. The app reads only the single image you pick and requests no photo, media or storage permission.
  • Safe link opening. Scanned http and https URLs can be opened in your default browser, with the destination shown before you go there.
  • Passkey QR handoff. Move a passkey between devices using the QR handoff flow.
  • Optional BYOK reputation checks. Tap a provider to check a URL against VirusTotal, urlscan.io or URLhaus. Each one requires your own API key, is disclosed before the first send, and never runs in the background.
  • FLAG_SECURE. Settings and the result sheet are protected from screenshots, screen recordings and the recent-apps thumbnail.
  • No analytics. No telemetry, no crash reporter, no advertising identifiers.

Permissions

The only permissions BokyQR declares.
PermissionWhyWhen
CAMERA To scan a QR or barcode. Requested once, on first launch. Nothing else uses it.
INTERNET To reach the reputation APIs you choose to query. Only while a check you started is running.

No photo, media, storage, location, contacts, microphone or advertising identifier is requested. No identifier of any kind is collected.

How reputation checks work

BokyQR ships no key. There is no shared key, no proxy and no demo key — the reputation providers do not work until you paste in your own API key. Keys you add in Settings are stored in EncryptedSharedPreferences, encrypted with an AES256_GCM master key held in the Android Keystore, and are excluded from cloud backup and device-to-device transfer.

A check never runs on scan, on app start, or on a schedule. It runs when you tap that provider's button. See the BokyQR section of the privacy policy for exactly what each provider receives.
