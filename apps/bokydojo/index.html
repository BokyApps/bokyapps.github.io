BokyDojo

Student Information System for dojos and martial arts clubs.

Self-hosted AGPL-3.0

BokyDojo is a Student Information System built for martial arts schools. It handles multi-dojo roll-up: attendance, ranking and grading, class scheduling, billing, and a parent portal. Self-host it with Docker today; a managed SaaS offering is a long-term goal, not the current shape of the project.

Features

  • Attendance. Class check-in, rosters and attendance history. The PWA keeps an offline attendance queue so a dropped connection mid-class does not lose your data.
  • Ranking and grading. Rank structure, promotion criteria and progress towards the next grade.
  • Scheduling. Timetables per dojo, with instructor and room assignments.
  • Billing. Memberships, invoicing and payment status alongside student records.
  • Parent portal. Parents see their own children's attendance, rank and invoices — and nothing else.
  • Multi-dojo roll-up. One operator running several clubs sees them in one place.

Your data

BokyDojo is self-hosted. Student and parent records stay on the instance operated by the club or organisation running it. BokyApps operates no cloud copy and no analytics. Note that student information is sensitive personal data: if you operate an instance, securing and backing it up is your responsibility as the operator.
